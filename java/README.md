# Объектная реализация на Java 21

FitnessClub.java содержит классы и интерфейс репозитория, сервис A1–A3
и демонстрацию. FitnessClubTest.java выполняет 24 проверки.
Инструкции сборки и общие правила — в README.md в корне проекта.
Внешние библиотеки не требуются. Результаты отказов не меняют состояние.
