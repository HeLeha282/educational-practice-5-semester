# Автоматизация абонементной системы фитнес-клуба (Python, процедурный подход)

Учебная практика, РТУ МИРЭА, кафедра игровой индустрии.

- `storage.py` – состояние в памяти (dict/list/set/tuple) и вспомогательные процедуры;
- `algorithms.py` – алгоритмы A1–A3 (дата окончания, допуск, заморозка);
- `main.py` – демонстрационный сценарий;
- `tests/test_algorithms.py` – модульные тесты (`unittest`).

Запуск: `python main.py`. Тесты: `python -m unittest discover -s tests -v`.
