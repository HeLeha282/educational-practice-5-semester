# Абонементная система фитнес-клуба

Учебная практика: исследовательский, аналитический и организационный этапы.

## Состав проекта

- `python/` — процедурные алгоритмы A1–A3, оформление продажи и демонстрация.
- `java/` — объектная реализация ядра A1–A3 на Java 21.
- `docs/` — актуальный отчёт по этапам 2–4.

## Правила периодов

Срок действия — `[start, end)`: `end` является первым днём без доступа.
Заморозка — `[from, to)`. Её начало должно лежать внутри срока до продления.
Смежные заморозки разрешены, пересекающиеся запрещены.
При отказе во входе состояние не изменяется, включая дату активации,
статус, остаток и журнал визитов. Активация pending происходит после всех проверок.

## Проверка Python

Из корня проекта:

```text
python -m unittest discover -s python/tests
```

Ожидаемый результат: 29 тестов, OK.
Демонстрация: `python python/main.py`.

## Проверка Java

Нужен JDK 21. Из каталога `java`:

```text
javac -encoding UTF-8 -d build FitnessClub.java FitnessClubTest.java
java -cp build FitnessClubTest
java -cp build FitnessClub
```

Ожидаемый результат проверок: `OK: 24 checks`.

Java этого этапа реализует расчёт срока, контроль допуска, выход и заморозку.
Регистрация принимает предварительно оформленный абонемент; платёжная часть
и операция продажи полностью в Java пока не перенесены.
Хранилище в памяти, операции последовательные. Для серверной версии нужны
транзакции и защита конкурентного доступа. Физическая БД — задача этапа 5.
